# uvrotate

## 题面（可直接粘贴）

UV 旋转与平铺。约束：必须用正交旋转矩阵（正交性误差 ≤1e-12），任意角度下长度/面积不变；多瓦片平铺接缝连续（相邻像素 UV 差有上界）；90 度整数倍结果精确；10 万次不超过 100 ms；非法参数与非有限输入要可区分报错。验收：cd uvrotate && python -m pytest tests -q -k rotate。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 并发安全
- 非有限输入分类报错
- 性能上界按题面

## 运行方式

```bash
cd uvrotate && python -m pytest tests -q
```
